# Secure-Campus-IPSec-VPN
Implementation of secure encrypted communication between two campuses using IPSec VPN, AES encryption, SHA hashing, and static routing in Cisco Packet Tracer.

## Project Overview
This project demonstrates secure encrypted communication between two geographically separated campuses using Site-to-Site IPSec VPN implementation.

The project was developed using Cisco Packet Tracer as part of a Cybersecurity & Ethical Hacking internship project.

---

## Objective
The main objective of this project is to establish secure communication between two campuses using industry-standard encryption policies and VPN tunneling techniques.

---

## Technologies Used
- Cisco Packet Tracer
- IPSec VPN
- AES Encryption
- SHA Hashing
- Static Routing
- WAN Serial Communication

---

## Features Implemented
- Two-campus secure network architecture
- Site-to-Site IPSec VPN tunnel
- AES and SHA encryption policies
- Secure inter-campus communication
- VPN tunnel verification
- Packet flow simulation

---

## Network Topology
The network consists of:
- Campus A network
- Campus B network
- Routers and switches
- WAN serial connection
- Secure IPSec VPN tunnel

---

## Security Implementation
The following security mechanisms were implemented:
- AES for data encryption
- SHA for integrity verification
- Pre-shared key authentication
- IPSec VPN tunneling
- Crypto map configuration

---

## Testing and Verification
The project was successfully tested using:
- Connectivity testing (Ping)
- IPSec security association verification
- VPN tunnel establishment verification
- Packet Tracer simulation mode

## Results
- Secure encrypted communication successfully established
- IPSec VPN tunnel successfully verified
- Successful inter-campus connectivity achieved
- Encrypted packet transmission validated
